# Changes to Colemak

This is the full list of changes that Programmer Colemak makes to Colemak.

## Base Layer

| Existing     | New          |
|--------------|--------------|
| \<backspace> | \<escape>    |
| g            | b            |
| [ ]          | \<backspace> |
| \<caps lock> | \<control>   |
| d            | g            |
| h            | k            |
| z            | x            |
| x            | c            |
| c            | d            |
| b            | \<circle>    |
| k            | m            |
| m            | h            |
| \<fn>        | z            |
| \<meta>      | \<fn>        |
